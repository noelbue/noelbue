## 🛠️ Projects

Most of my work lives in private client repositories. A few highlights:

- **[PostCard Creator](https://www.brueggli-admedia.ch/) for Swiss Post** — Led and co-developed the modernization of a legacy server system into a modern TypeScript / Node.js / PostgreSQL architecture, covering the full chain from data ingestion and validation to print, dispatch and billing. Built with AI-assisted agentic coding.
- **[Fridai](https://fridai.swiss)** — Privacy-first AI platform for the Swiss social sector. Owned requirements and solution design, ran the applied research: speech-to-text evaluation (Whisper, Swiss-German models, WER/BLEU), Mistral OCR incl. nDSG clearance, local LLMs (GPT-OSS, Qwen, Gemma), embeddings and reranking.
- **[ProspectHub](https://app.prospecthub.ch)** — B2B lead generation and cold outreach SaaS for Swiss SMBs that I build and operate in production. Website analysis and quality scoring, lead crawling, AI-generated outreach (OpenAI and Claude), Zefix enrichment. Next.js 16, React 19, TypeScript, PostgreSQL, Prisma, NextAuth, Turborepo, Docker on Hetzner.
- **[noelbuergler.ch](https://noelbuergler.ch)** — My CV website. Gatsby, React, GraphQL, bilingual (DE/EN), Liquid-Glass design, View Transitions API, deployed on Netlify.
- **Enfocus Switch & InDesign Server workflows** — Custom Node.js and ExtendScript automations for publishing, one of which saves one to two hours of manual work every day.
