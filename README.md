On the side I run **[Bürgler Business Solutions](https://b-business-solutions.ch)**, building publishing automation (InDesign Server, Enfocus Switch, EasyCatalog) and full-stack web applications (Next.js, React, headless CMS) for my own clients — including **ProspectHub**, a SaaS platform I build and operate in production.
